The Nopwara theme and all nine Nopwara plugins in one upload for nopCommerce 5.00.

**Install:** download `nopwara-suite-<version>.zip` below, then follow the [install steps](https://github.com/sohelrana09/nopwara-suite#install). Already on an earlier version? Upload the new zip and restart; plugins update themselves (see [Update](https://github.com/sohelrana09/nopwara-suite#update)).

## What's new in v1.1.1

**[Nopwara Mega Menu](https://github.com/sohelrana09/nopwara-mega-menu) 1.01** (fixes found in a code review):

- A "View all" text with braces in it (e.g. `Shop {all}`) no longer hides the whole mega menu.
- A topic content column skips password-protected and unavailable topics, so their text isn't shown in the menu.
- The extras edit page checks field lengths and the banner link (it must start with `/` or `http(s)://`; `javascript:` links are refused), and a failed save no longer shows half-saved values on the storefront.
- Editing the raw HTML column needs the *Topics: create, edit, delete* permission, since it's shown as-is on every page.

All other items are unchanged from v1.1.0.
